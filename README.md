One line, at most 200 characters: a joke about office life — a boss calls a
meeting to discuss why there are too many meetings, it runs over, and now
the follow-up has a follow-up.

`main.py` (standard library only) writes the joke to `/output/entry.txt`
and verifies the round-trip content is byte-identical and 1–200 characters.

Run it:

```sh
python3 main.py
```
